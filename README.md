# Kevin Gustavo Castillo Onofa — Portfolio

Portfolio bilingüe (español e inglés) creado con React y Vite.

## Desarrollo local

```bash
npm install
npm run dev
```

## Despliegue

El workflow de GitHub Actions compila el proyecto en cada push a `main` y publica `dist` en GitHub Pages. En **Settings → Pages → Build and deployment**, selecciona **GitHub Actions** como fuente. También se puede ejecutar manualmente desde **Actions**.

Los PDF descargables están en `public/cvs`; el idioma seleccionado determina cuál se descarga.
